## The three signals

Core Web Vitals focus on loading performance, responsiveness and visual stability.

- **LCP** measures how quickly the main content becomes visible.
- **INP** measures responsiveness to user interactions.
- **CLS** measures unexpected layout movement.

## Practical improvements

Prefer static generation for content that does not need a database request at runtime. Reserve space for images, avoid layout shifts, keep JavaScript bundles focused and test on real mobile hardware.

## Why this project is fast

The blog pages are statically generated. That means a visitor receives pre-built HTML rather than waiting for a server to assemble an article on every request.
