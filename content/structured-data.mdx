## What structured data does

Structured data is machine-readable information embedded in a webpage. JSON-LD is a common format because it keeps the markup separate from visible article content.

## Article schema

This project emits an `Article` object containing the headline, description, publication date and author. Search engines can use these signals to better understand the page.

## Keep it truthful

Never add structured-data fields that are not represented by the page. Schema should describe real content, not manufacture rankings.
